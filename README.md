# GigaChat-Shell

> Консольный ИИ-помощник на базе GigaChat API для Linux, macOS и Windows.

В репозитории представлены две реализации утилиты `gpt`:
- Bash-скрипт для Linux и macOS.
- Модуль PowerShell 7 для Windows.

## Особенности реализации

- **Минимум зависимостей.** Bash-реализация использует `curl` для HTTP-запросов и `jq` для обработки JSON. Версия для Windows реализована на PowerShell 7 без дополнительных модулей.
- **Без промежуточных языков и сред выполнения.** Скрипты используют штатные средства командной оболочки и не требуют установки Python, Node.js или других дополнительных сред.
- **Единый интерфейс.** В Linux, macOS и Windows утилита вызывается командой `gpt`. Основные принципы работы и интерфейс одинаковы в обеих реализациях; отдельные возможности могут различаться.
- **Интеграция с командной строкой.** Запросы можно формировать с помощью параметров и передавать данные через стандартный поток ввода (`stdin`), в том числе из файлов и других команд.
- **Минималистичная архитектура.** Реализация ориентирована на личное использование и решение повседневных задач из консоли. Развитие дополнительных функций и создание универсального фреймворка не входят в задачи проекта.

## Подготовка

### 1. Получение API-ключа

1. Авторизуйтесь в [GigaChat API](https://developers.sber.ru/studio/login) через Сбер ID.
2. Создайте проект и выберите инструмент «GigaChat API».
3. В настройках проекта получите Authorization Key и сохраните его. Ключ показывается только один раз.
4. Для физических лиц используйте scope `GIGACHAT_API_PERS`.

Подробная инструкция: [Быстрый старт GigaChat API](https://developers.sber.ru/docs/ru/gigachat/individuals-quickstart).

### 2. Установка сертификатов

Для работы с GigaChat API установите [сертификаты НУЦ Минцифры](https://developers.sber.ru/docs/ru/gigachat/certificates).

Следуйте инструкциям для вашей операционной системы. Не отключайте проверку TLS-сертификатов для обхода ошибок соединения.

### 3. Установка зависимостей

- **Linux и macOS:** `curl` и `jq`.
- **Windows:** PowerShell 7. Внешние зависимости для работы модуля не требуются.

## Установка и запуск

### Linux и macOS

```bash
export GIGACHAT_CREDENTIALS='Ваш_ключ'

sudo cp gpt.sh /usr/local/bin/gpt
sudo chmod +x /usr/local/bin/gpt
```

Переменная окружения должна быть задана в той оболочке, из которой запускается утилита. Для постоянного использования её можно добавить в конфигурацию оболочки.

### Windows, PowerShell 7

```powershell
$env:GIGACHAT_CREDENTIALS = 'Ваш_ключ'

$modulePath = "$HOME\Documents\PowerShell\Modules\GigaChat"
New-Item -ItemType Directory -Force -Path $modulePath
Copy-Item .\GigaChat.psd1 $modulePath
Copy-Item .\GigaChat.psm1 $modulePath
```

После установки перезапусти PowerShell. Если каталог Documents перенаправлен в OneDrive или изменён настройками системы, путь установки может потребовать корректировки.

## Использование

### Примеры для Linux и MacOS

```bash
# Обычный запрос
gpt "Объясни разницу между TCP и UDP"

# Запрос с кастомным промптом
gpt -s "Ты опытный Linux-администратор. Отвечай кратко, предлагай конкретные команды." "Как найти процесс, занимающий порт 8080?"

# Анализ системного журнала
journalctl -p err -n 50 | gpt "Проанализируй ошибки и предложи варианты диагностики"

# Проверка конфигурации Nginx
cat /etc/nginx/nginx.conf | gpt -s "Проверь конфигурацию на типичные ошибки и потенциальные проблемы"

# Анализ сетевой диагностики
{ ip addr; ip route; } | gpt -s "Проанализируй сетевую конфигурацию и укажи возможные проблемы"
```

### Примеры для Windows

> В версии для Windows реализована память диалога: флаг -m позволяет продолжить предыдущий диалог, передавая модели контекст последних запросов и ответов. Без этого флага история очищается. Модуль хранит до 10 пар вопрос-ответ в рамках текущей сессии PowerShell.

```powershell
# Обычный запрос
gpt "Объясни разницу между TCP и UDP"

# Запрос с кастомным промптом
gpt -s "Ты опытный Windows администратор. Отвечай кратко, предлагай конкретные команды." "Как найти процесс, занимающий порт 8080?"

# Запрос анализом файла
gpt -s "Проанализируй код модуля на ошибки" (Get-Content "$HOME\Documents\PowerShell\Modules\GigaChat\GigaChat.psm1" -Raw)

# Начало диалога
gpt "Что делает Get-ChildItem?"

# Включаем память
gpt -m "Как вывести только файлы?"

# Второй и третий запросы учитывают предыдущий контекст
gpt -m "А как отсортировать их по размеру?"
```
